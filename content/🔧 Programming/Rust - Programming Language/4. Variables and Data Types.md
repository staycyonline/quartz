
## Variables
---

``` Rust
let x = 5;
let mut y = 10;
y = 15; 

const MAX_POINTS: u32 = 100_000
```

- All variables are immutable by default
- While defining constants we have to specify type  and value- here unsigned int of 32 bit
- We can define types for variables
